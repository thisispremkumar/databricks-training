# Week 1: Databricks SQL Fundamentals

This directory contains materials and exercises for the first week of Databricks training. The focus is on environment setup and mastering basic SQL operations within a Lakehouse environment.

---

## 🛠️ Environment Setup
* **Cluster Configuration:** Created and configured a personal Compute Cluster.
* **Workspace Navigation:** Explored Databricks Notebooks and the SQL Warehouse.
* **Data Ingestion:** Practiced uploading local CSV/JSON files to the **DBFS (Databricks File System)**.

---

## 📊 SQL Mastery
During this week, I practiced fundamental SQL commands to manipulate and query data:

### 1. Data Definition Language (DDL)
* Creating databases and schemas.
* Defining Managed vs. External tables.
* `CREATE`, `ALTER`, and `DROP` statements.

### 2. Data Manipulation Language (DML)
* Inserting records into existing tables.
* Updating and deleting data using Delta Lake's ACID capabilities.

### 3. Data Querying (DQL)
* **Basic Filtering:** Using `SELECT`, `FROM`, and `WHERE`.
* **Aggregation:** Summarizing data with `GROUP BY`, `COUNT`, `SUM`, and `AVG`.
* **Ordering:** Sorting results using `ORDER BY` and `LIMIT`.
* **Joining:** Combining datasets using `INNER JOIN`, `LEFT JOIN`, and `FULL OUTER JOIN`.
